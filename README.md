# fakepose-mcp

First-person hands on a gun, posed the way games do it: authored grip presets on the gun's sockets, fingers curled to contact, two-bone IK, and a check that the first-person camera sees no clipping. It runs inside Weapon Lab's Gun Kit hands step (`pose_engine: "fakepose"`, the default).
